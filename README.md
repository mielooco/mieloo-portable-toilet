# MIELOO CORPORATION — ポータブル水洗トイレ

Japanese / English customer introduction website. Static HTML, CSS and JavaScript; no build step or backend is required.

## Local preview

Serve this directory with any static HTTP server. Open `index.html` through that server. Language switching, image galleries, video and the planning calculator work in the browser.

## GitHub Pages

The website files are at the repository root. If the account plan supports Pages for private repositories, choose **Settings → Pages → Deploy from a branch → main → / (root)**. `.nojekyll` allows the static files to be published directly.

Private repository access and website access are separate. Confirm the resulting site audience before sending its URL to customers. Do not make the repository public to enable Pages without owner approval.

## Content

The calculator uses illustrative inputs, not validated consumption or autonomous operation guarantees. Water, suitable disposal, cleaning and safe placement remain necessary. Generated scene images are labelled as illustrations, not actual installations. Product figures come from supplied manufacturer documents. Confirm the supplied product version before ordering.

The source package includes only website files and referenced assets. Internal quotation calculations and account credentials are not included.
